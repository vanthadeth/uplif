# UPLIF brand assets

`app-icons/` holds the source SVG for each app icon (512 x 512, flat colours, no gradients): the UPLIF pixel arrow on a coloured tile with a white badge for the app.

| App | Display name | Tile colour |
| --- | --- | --- |
| console | UPLIF Admin | #1E293B |
| staff | UPLIF Me | #2563EB |
| attendance (module) | UPLIF Time | #0D9488 |
| sales | UPLIF Go | #EA580C |
| invoice | UPLIF Orders | #7C3AED |
| stock | UPLIF Stock | #6B7280 |
| pos | UPLIF POS | #DB2777 |
| sites | UPLIF Sites | #DC2626 |
| admin (platform super-admin) | UPLIF Platform | #4338CA |

PWA sizes in each app's `public/icons/`: icon-192, icon-512 (rounded tile on transparent), maskable-512 (full-bleed, artwork scaled to 72% for the safe zone) and apple-touch-icon (180, full-bleed). Names are display names only; module keys and folders do not change. Trademark and domain for UPLIF are not checked yet.
